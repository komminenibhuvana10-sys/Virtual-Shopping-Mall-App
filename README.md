# Virtual-Shopping-Mall-App
Virtual Shopping Mall Mobile App is a modern 3D multi-floor retail application built with HTML5, CSS3 Glassmorphism, and Vanilla JS. Features an interactive glass elevator, 5 department floors (Cosmetics, Fashion, Menswear, Kids &amp; Books), smart cart, wishlist, multi-gateway checkout (Card/UPI/Wallet), live order tracking, and printable tax invoices
